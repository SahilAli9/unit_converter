Unit Converter 🐍

A simple, menu-based unit converter made with Python. This is a beginner project created to practise Python functions, loops, conditional statements, user input, and terminal output.

📌 About the Project

Unit Converter is a command-line program that aims to convert different types of units, such as length, weight, volume, temperature, time, and data.

The project is built using Python and is designed to be simple and easy to use.

I created this project as part of my Python learning journey. My goal is to improve my programming skills by building practical projects.

✨ Features

- 📏 Length conversion
- ⚖️ Weight conversion
- 🧪 Volume conversion
- 💾 Data unit conversion
- 🌡️ Temperature conversion
- ⏱️ Time conversion
- 📅 Days and weeks conversion
- 🎨 Coloured terminal output using Colorama
- ⏳ Simple loading animation
- 🧩 Functions for conversion calculations
- 🔢 Numbered menus for selecting options


🛠️ Technologies Used

- Python — Main programming language
- Colorama — For coloured terminal text
- Subprocess — For clearing the terminal 
- Time — For the loading animation

📋 Requirements

Before running this project, you need:

- Python 3.12 or newer
- A terminal or command-line environment

🚀 Installation

1. Clone the repository

Open your terminal and run:

git clone https://github.com/SahilAli9/unit_converter

2. Open the project folder

cd unit_converter

3. Install the required package

pip install -r requirements.txt 

4. Run the program

python unit_converter.py
